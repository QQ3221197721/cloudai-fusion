## 六、关键提醒与风险说明

### 1. AutoDL 发票能力 ✅
- **确认可开**：增值税普通发票 + 增值税专用发票
- 单次满 ¥10 即可开票（验证任务可能需合并充值开票）
- 电子发票即时出具

### 2. Spot 竞价中断风险 ⚠️
- **阿里云**：中断前 5 分钟通知，需做 checkpoint
- **腾讯云**：中断前 2 分钟通知
- **风险缓解**：验证任务通常 2-4h，可分多次跑；选择冷门时段(凌晨)中断概率低
- **建议**：M3 多节点验证用按量而非 Spot（避免中途中断导致重跑）

### 3. 专票抵扣可行性
- AutoDL / 阿里云 / 腾讯云 / UCloud / 华为云 **均支持增值税专票**
- 专票可用于企业进项税抵扣（税率通常 6% 信息技术服务）
- 个人用户建议开普票即可

### 4. InfiniBand 多节点验证替代方案
- AutoDL 已限制多机互联（仅 A100 部分机房支持）
- **推荐**：阿里云 SCC（超级计算集群）竞价实例，自带 RDMA/InfiniBand
- **备选**：华为云 CCE + P2s 集群模式
- **最便宜替代**：用 TCP 模拟 RDMA 逻辑验证（¥0，仅需 2 台普通实例），后续再上真实 IB

### 5. 各平台适合的验证场景

| 平台 | 最适合验证 | 理由 |
|------|-----------|------|
| AutoDL | M2 MIG 逻辑验证 | A100 便宜、秒级计费、开机即用 |
| 阿里云 g7t | M5 SGX 验证 | 唯一国内主流支持 vSGX 的云 |
| 阿里云 SCC Spot | M3 InfiniBand | 真实 IB 网络、竞价便宜 |
| UCloud 9.9元日卡 | 快速功能验证 | 极低成本入门 |

- 平台：AutoDL

- 时长：4h
- 费用：约 ¥14-27

- 操作：开 2 台带 RDMA 的实例，跑 CRIU checkpoint + 跨节点恢复
- 时长：8h（含环境搭建）
- 费用：约 ¥60-150

## 九、诚实说明

1. **价格波动**：GPU 云租赁价格变化频繁（周级别波动 10-20%），上述数据为 2026年7-8月快照
2. **竞价实例价格**：Spot 价格按供需实时浮动，上表给的是历史区间估算值，非实时报价
3. **AutoDL H100**：H100 价格为推算值（基于 A100 的 1.5-2x 倍率），具体以官网实时库存为准
4. **阿里云 SGX 价格**：g7t/c7t 按量价格为基于同级别规格推算，建议开通前在价格计算器确认
5. **M3 InfiniBand 真实验证**：最便宜的真 IB 验证仍需阿里云 SCC 或华为云 HPC 集群，单纯 AutoDL 无法满足
