# T2 硬件验证「国内可开票」采购需求单

> **文档版本**: v1.0  
> **生成日期**: 2026-08-20  
> **用途**: CloudAI Fusion 平台 M2/M3/M5 三个 HARD 模块的真实硬件 benchmark 验证采购  
> **原则**: 国内平台 + 可开增值税专用发票 + 云租赁优先（随用随停）

## 1. 需求单总览

| 模块 | 验证目标 | 最低硬件规格 | 网络要求 | OS 要求 |
|------|----------|-------------|----------|---------|
| **M2 MIG** | NVIDIA MIG 多实例 GPU 分区验证 | NVIDIA A100 80GB 或 H100（支持 MIG 7 分区）≥1卡 | 普通 VPC 即可 | Ubuntu 22.04+ / CentOS 8+，CUDA 12+ |
| **M3 CRIU+IB** | 容器热迁移(CRIU) + InfiniBand/RDMA 多节点通信 | ≥2 节点，每节点 ≥1 GPU（A100），节点间 RDMA/IB ≥100Gbps | InfiniBand / eRDMA / RoCEv2 高速互联 | Ubuntu 22.04+，内核 5.15+，CRIU 3.17+ |
| **M5 SGX** | Intel SGX enclave 创建与远程证明 | Intel Ice Lake+ / Sapphire Rapids+ CPU，SGX EPC ≥64MB | 普通 VPC | Ubuntu 22.04 / Alibaba Cloud Linux 3，SGX SDK 2.19+ |

## 5. 采购与开票注意事项

### 5.1 云平台开票流程

| 平台 | 发票类型 | 税率 | 开票方式 | 备注 |
|------|----------|------|----------|------|
| 阿里云 | 增值税专票 | 6%（技术服务） | 控制台 → 费用 → 发票管理，企业认证后自动开 | 需上传营业执照+税务登记 |
| 腾讯云 | 增值税专票 | 6% | 控制台 → 费用中心 → 发票管理 | 同上 |
| 百度智能云 | 增值税专票 | 6% | 控制台 → 财务 → 发票 | 同上 |
| 火山引擎 | 增值税专票 | 6% | 控制台 → 费用 → 发票 | 字节跳动旗下，国内主体 |
| AWS 中国 | 增值税专票 | 6% | 控制台 → Billing → 发票管理 | 由光环新网/西云数据运营，国内主体开票 |

### 5.2 配额申请注意

| 实例类型 | 是否需工单 | 预计审批时长 | 申请方式 |
|----------|-----------|-------------|----------|
| A100 单卡（gn7e/GT4） | **通常需要** | 1-2 工作日 | 控制台提工单，说明用途 |
| SCC/HCC 集群 | **必须申请** | 2-5 工作日 | 提工单 + 可能需签承诺函 |
| SGX 实例（g7t/c7t） | 一般无需 | 即开即用 | 直接购买 |

### 5.3 技术注意事项

1. **MIG 开启**：A100 实例需手动执行 `nvidia-smi -mig 1` 然后创建 GI/CI 分区，云实例默认未开启 MIG
2. **eRDMA vs IB**：阿里云 eRDMA 是软件定义 RDMA，延迟略高于硬件 IB（~5μs vs ~1μs），但对验证 CRIU 迁移逻辑足够
3. **CRIU 权限**：需要 root + `CAP_SYS_ADMIN`，裸金属实例或特权容器可满足
4. **SGX BIOS**：云实例已预配置 SGX BIOS 选项，无需手动开启
5. **数据安全**：验证完毕后及时释放实例、清理数据，避免持续计费
