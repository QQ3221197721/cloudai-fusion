## 🧪 What You Can Do After Starting

Once the local plane is running, explore these features:

### Real Instance CRUD (in-memory)

```powershell
# Create 3 instances
for ($i = 1; $i -le 3; $i++) {
    $body = "{\""name\"":\"test-$i\", \""type\"":\""m5.large\"" }"
    Invoke-WebRequest -Uri http://localhost:8099/api/v1/cloud/instances -Method POST -Headers @{"Content-Type"="application/json"} -Body $body -UseBasicParsing | Select-Object -ExpandProperty Content
}

# List them
Invoke-WebRequest -Uri http://localhost:8099/api/v1/cloud/instances -UseBasicParsing | Select-Object -ExpandProperty Content
```

**Result:** All three instances have deterministic IDs (`mock-000001`, `mock-000002`, `mock-000003`) derived from an internal counter—no randomness, no cloud API calls.

### Evidence Chain Verification

The `.caf/evidence.chain` contains all boot and instance-create attestation records signed with your project's Ed25519 key. Verify offline:

```powershell
.\cafctl.exe verify --key-file .caf/public.pem
```

Every attestation can be independently validated by third parties who hold your public key.

### Capabilities Transparency

The `/api/v1/capabilities` endpoint answers the fundamental question: **"What is real and what is simulated?"**

```json
{
  "run_mode": "simulation",
  "all_real": false,
  "simulated_count": 3,
  "backends": [
    {
      "component": "cloudprovider",
      "mode": "real",
      "driver": "localmock",
      "detail": "pkg/cloudprovider LocalMockProvider — real in-memory CRUD, zero credentials"
    },
    // ... other subsystems labeled honestly
  ],
  "simulated": [
    // ... exactly which ones are simulated
  ]
}
```

This honesty contract prevents "fake-it-till-you-make-it" bugs during development.
