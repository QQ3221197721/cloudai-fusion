WHAT THIS BENCHMARK ACTUALLY MEASURES (HONEST SCOPING)
================================================================================

THIS BENCHMARK DOES MEASURE:
  ✓ The PURE DISPATH TAX each abstraction adds ON TOP OF the cloud API call
  ✓ Our in-process Go interface + registry (microseconds at worst)
  ✓ Terraform's go-plugin gRPC IPC (hundreds of microseconds minimum)
  ✓ Architecture-level difference: in-process vs out-of-process dispatch

THIS BENCHMARK DOES NOT MEASURE:
  ✗ Actual AWS API round-trip latency (~100ms network, identical for both)
  ✗ Cloud provider authentication overhead (same auth library on both sides)
  ✗ Downstream resource provisioning time (not available without live AWS)

WHY THIS IS FAIR:
  When comparing abstraction LAYERS (not full-stack providers), you must
  isolate the dispatch mechanism from the cloud-specific implementation. That's
  exactly what we did. Adding the same AWS API call to both sides would just
  add noise, not signal.
