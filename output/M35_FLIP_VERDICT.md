## Root Cause Analysis

The correctness failures trace to three semantic differences:

1. **Default Effect Semantics**
   - Native: `default allow := false` → implicit deny
   - OPA: No explicit default in some rules → depends on Rego evaluator behavior

2. **List Matching Logic**  
   ```go
   // Native: exact set membership check
   if len(rule.matchRoles) > 0 && !rule.matchRoles[req.SubjectRole] { return false }
   
   // OPA: some-in comprehension (different quantifier semantics)
   some role in [...]
       input.subject_role == role
   ```

3. **AND vs OR Composition**
   - Native requires ALL conditions match
   - OPA's natural-language grammar allows partial satisfaction
